# Design Specification

## Overall UX Philosophy
The RINK Technology Transfer Portal is designed with a premium, clean, and professional aesthetic, tailored specifically for investors, researchers, and entrepreneurs. The UI uses Tailwind CSS for robust layout and styling, combined with Framer Motion for subtle, modern micro-interactions that make the platform feel responsive and alive.

## Key Views

### Homepage
- **Hero Section:** Clear value proposition driving users to search or explore the repository.
- **Featured Technologies:** A curated carousel or grid highlighting technologies marked internally with "High" or "Very High" startup potential.
- **Browse by Sector/Institution:** Quick visual entry points using distinct icons and colors for specific sectors to guide user journeys.

### Technology Exploration (Search/Filter)
- **Search Bar:** Prominent search input with real-time keystroke feedback (powered instantly by Orama).
- **Filter Sidebar/Drawer:** Allows users to refine the catalog by Sector, Institution, IP Status, and Technology Readiness Level (TRL).
- **Empty States:** Clear messaging when no technologies match the applied filters, paired with a quick action to "Clear Filters" rather than leaving the user at a dead end.
- **Responsive Layout:** The desktop viewport utilizes a persistent sidebar for filters; the mobile viewport abstracts this into a swipeable bottom sheet or overlay drawer to maximize screen real estate.

### Technology Detail Page
- **Header:** Clean presentation of the technology title, institution, and primary sector.
- **Visuals:** Featured image or diagram if available, rendered dynamically via the WebP assets generated by the sync script.
- **Content Blocks:** Information is chunked logically (Problem Solved, Description, Applications) to prevent text fatigue.
- **Status Badges:** Visual indicators for TRL and IP Status, using semantic colors (e.g., green for granted patents, yellow for pending).
- **Call to Action:** A prominent "Express Interest" (EOI) button that provides contact routing.

## Design Decisions & Guidelines
- **Color Palette:** Professional tones aligned with Kerala Startup Mission branding, utilizing clear semantic colors for statuses.
- **Typography:** Modern sans-serif stack (e.g., Inter or Roboto) prioritizing legibility in dense data views.
- **Animations:** Framer Motion is utilized for smooth page transitions, card hover states, and modal entries. Animations are deliberate, snappy, and do not impede fast navigation.
- **Mobile-First:** All complex layouts (like the filter system and tabular data) gracefully degrade to mobile-friendly stacked or swipeable views.

## User Interaction Patterns
- **URL-Driven State:** Search queries and active filters must be reflected in the URL parameters. This ensures users can share specific search results or return to their exact state via browser history.
- **Progressive Disclosure:** Complex legal patent text or excessively lengthy descriptions may be truncated with "Read More" patterns to maintain a clean layout while keeping detailed data accessible.
